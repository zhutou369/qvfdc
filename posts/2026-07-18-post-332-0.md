## 为什么自动化WhatsApp问候至关重要？

在快节奏的商业世界中，即时响应是建立客户信任和促进销售的关键。为WhatsApp网页版配置自动打招呼脚本，能够带来多方面的显著优势：

### 提升响应速度与效率
手动发送欢迎消息会耗费大量时间，尤其是在高流量时段。自动脚本可以在新对话建立的第一时间发送预设问候，确保客户在等待人工回复之前感受到被重视，从而极大提升响应效率，释放你的团队去处理更复杂的咨询。

### 优化客户首次体验
一个及时、友好的自动问候能为客户留下积极的第一印象。它不仅能立即确认消息已被接收，还可以提供下一步的指导，例如告知客户预期回复时间，或引导他们访问FAQ页面，从而提升整体的客户满意度。

### 助力潜在客户培育与资格筛选
自动问候脚本可以不仅仅是简单的“你好”。你可以巧妙地在欢迎语中嵌入问题，收集客户需求或兴趣点，甚至引导他们填写一个简短的表单。这有助于你在人工介入前对潜在客户进行初步的资格筛选，使你的销售或支持团队能更专注于高质量的潜在客户。

### 实现业务运营的规模化
对于拥有大量客户或潜在客户的业务而言，自动化是实现规模化的必由之路。通过脚本，你可以轻松应对不断增长的对话量，而无需按比例增加人力，这对于资源有限的初创企业或小型团队尤为重要。

## 理解自动打招呼脚本的技术原理

要配置自动打招呼脚本，我们首先需要理解其背后的基本技术原理。这主要涉及到浏览器扩展（如Tampermonkey或Greasemonkey）和JavaScript用户脚本。

### 浏览器用户脚本与扩展
浏览器扩展（如Chrome的Tampermonkey或Firefox的Greasemonkey）提供了一个沙盒环境，允许用户运行自定义的JavaScript代码来修改网页的行为。这些自定义代码被称为“用户脚本”。它们可以读取、修改页面的DOM结构，监听事件，甚至发出网络请求，从而实现对网页功能的增强或自动化。

### DOM操作与事件监听
WhatsApp网页版是一个典型的单页应用（SPA）。当有新消息或新对话出现时，页面的DOM结构会发生变化。我们的脚本需要：
1.  **监听DOM变化**：通过`MutationObserver`或定时器轮询，检测是否有新的未读对话（尤其是新联系人的对话）出现。
2.  **识别新对话**：根据WhatsApp网页版的DOM结构，精确识别出哪些是新的、未曾打招呼的对话。
3.  **模拟用户操作**：一旦识别出目标对话，脚本需要模拟点击该对话，激活消息输入框，输入预设的问候语，并模拟点击发送按钮。这通常通过操作HTML元素（如`querySelector`、`value`）和触发事件（如`click`、`input`、`keydown`）来实现。

### API限制与脚本边界
需要明确的是，这种方法并非通过WhatsApp官方API实现，而是直接在浏览器层面对网页进行操作。这意味着它受到浏览器环境和WhatsApp网页版UI结构的限制。如果WhatsApp网页版更新了其UI，脚本可能需要相应调整。此外，过度或不当使用自动化脚本可能违反WhatsApp的服务条款，甚至有被封号的风险，因此在使用时务必谨慎并遵守最佳实践。

## 手把手配置自动打招呼脚本

现在，让我们一步步来配置你的WhatsApp网页版自动打招呼脚本。

### 1. 安装Tampermonkey扩展
如果你尚未安装Tampermonkey，请前往你浏览器的扩展商店进行安装。安装完成后，你会发现浏览器右上角出现一个Tampermonkey的图标。

### 2. 创建一个新的用户脚本
点击Tampermonkey图标，然后选择“创建新脚本...” (Create a new script...)。这将打开一个新的编辑器窗口，其中包含一个基本的脚本模板。

### 3. 复制代码并粘贴到编辑器
以下是一个功能相对完善的自动打招呼脚本示例。请将以下代码复制并粘贴到Tampermonkey的编辑器中，替换掉原有的模板代码。

```javascript
// ==UserScript==
// @name         WhatsApp Web Auto Greeter
// @namespace    http://tampermonkey.net/
// @version      1.3
// @description  Automatically sends a customizable greeting message to new or specific WhatsApp Web chats.
// @author       YourName
// @match        https://web.whatsapp.com/*
// @grant        none
// ==/UserScript==

(function() {
    'use strict';

    // --- Configuration ---
    const GREETING_MESSAGE = "您好！感谢您的联系。我是自动客服，请问有什么可以帮您？我们将尽快回复您的人工服务请求。"; // Your custom greeting message
    const MESSAGE_DELAY_MS = 2000; // Delay before sending message after selecting chat (in milliseconds)
    const RECENT_CHAT_THRESHOLD_MS = 60 * 1000; // Consider chats within this timeframe as "recent" for processing (1 minute)
    const MAX_GREETINGS_PER_CHAT = 1; // How many times to greet a single chat (1 for once)

    // Optional: List of contact names/numbers to specifically target or exclude
    const TARGET_CONTACTS = []; // e.g., ["John Doe", "1234567890", "Family Group"] - leave empty to greet all
    const EXCLUDE_CONTACTS = []; // e.g., ["Spam Bot", "My Boss"]

    // --- Internal State (Do not modify) ---
    const greetedChats = {}; // Stores chat IDs that have been greeted

    // --- Utility Functions ---
    function getChatId(chatElement) {
        // WhatsApp Web chat list item typically has data-id attribute or can be derived from aria-label
        return chatElement.getAttribute('data-id') || chatElement.id || chatElement.querySelector('[title]')?.title;
    }

    function simulateInput(element, text) {
        const dataTransfer = new DataTransfer();
        element.focus();
        element.dispatchEvent(new Event('focus', { bubbles: true }));
        element.innerHTML = text; // Directly set content for rich text editors
        element.dispatchEvent(new Event('input', { bubbles: true })); // Trigger input event
        element.dispatchEvent(new Event('change', { bubbles: true })); // Trigger change event
    }

    function simulateClick(element) {
        if (element) {
            element.click();
        }
    }

    function getChatTitle(chatElement) {
        return chatElement.querySelector('[title]')?.title || chatElement.querySelector('span[dir="auto"]')?.[0]?.textContent || '';
    }

    function isGreetingRequired(chatElement) {
        const chatId = getChatId(chatElement);
        if (!chatId) return false;

        const chatTitle = getChatTitle(chatElement);

        // Check if excluded
        if (EXCLUDE_CONTACTS.some(contact => chatTitle.includes(contact))) {
            return false;
        }

        // Check if targeted (if TARGET_CONTACTS is not empty)
        if (TARGET_CONTACTS.length > 0 && !TARGET_CONTACTS.some(contact => chatTitle.includes(contact))) {
            return false;
        }

        // Check if already greeted
        if (greetedChats[chatId] && greetedChats[chatId] >= MAX_GREETINGS_PER_CHAT) {
            return false;
        }

        // Check for unread indicator
        const unreadIndicator = chatElement.querySelector('[data-icon="unread-count"]');
        if (!unreadIndicator) {
            return false; // No unread messages
        }

        // Check if the last message was sent by us (to avoid self-greeting loops)
        // This is a more complex check and might require accessing the currently active chat's message list
        // For simplicity, we assume if an unread indicator exists, it might be new.
        // A robust solution would involve checking the latest message sender in the active chat.

        return true;
    }

    function processChat(chatElement) {
        const chatId = getChatId(chatElement);
        if (!chatId || !isGreetingRequired(chatElement)) {
            return;
        }

        console.log(`[Auto Greeter] Processing chat: ${getChatTitle(chatElement)} (ID: ${chatId})`);

        // Click on the chat to open it
        simulateClick(chatElement);

        // Add to greeted list immediately to prevent re-processing
        greetedChats[chatId] = (greetedChats[chatId] || 0) + 1;

        // Wait for chat to load and input field to become available
        setTimeout(() => {
            const messageInput = document.querySelector('[data-tab="10"]'); // WhatsApp's message input field selector
            const sendButton = document.querySelector('[data-icon="send"]'); // WhatsApp's send button selector

            if (messageInput && sendButton) {
                simulateInput(messageInput, GREETING_MESSAGE);
                setTimeout(() => {
                    simulateClick(sendButton);
                    console.log(`[Auto Greeter] Message sent to ${getChatTitle(chatElement)}`);
                }, 500); // Small delay before sending after inputting text
            } else {
                console.warn(`[Auto Greeter] Could not find message input or send button for chat ${getChatTitle(chatElement)}`);
            }
        }, MESSAGE_DELAY_MS);
    }

    // --- Main Observer Logic ---
    const observer = new MutationObserver((mutations) => {
        mutations.forEach((mutation) => {
            if (mutation.type === 'childList' && mutation.addedNodes.length > 0) {
                mutation.addedNodes.forEach((node) => {
                    if (node.nodeType === 1 && node.matches('.x1c4vz4f.x2lahu6')) { // Selector for a chat item in the left panel
                        const chatListItems = node.querySelectorAll('[role="listitem"]');
                        chatListItems.forEach(item => {
                            if (isGreetingRequired(item)) {
                                processChat(item);
                            }
                        });
                    }
                });
            } else if (mutation.type === 'attributes' && mutation.attributeName === 'class') {
                // Handle cases where existing chat elements change class (e.g., unread status)
                if (mutation.target.matches('[role="listitem"]') && isGreetingRequired(mutation.target)) {
                     processChat(mutation.target);
                }
            }
        });
    });

    function startObserver() {
        const chatList = document.querySelector('[role="list"][aria-label="Chat list"]'); // Selector for the main chat list container
        if (chatList) {
            observer.observe(chatList, { childList: true, subtree: true, attributes: true });
            console.log('[Auto Greeter] WhatsApp Web chat list observer started.');

            // Initial scan for existing unread chats
            chatList.querySelectorAll('[role="listitem"]').forEach(item => {
                if (isGreetingRequired(item)) {
                    processChat(item);
                }
            });
        } else {
            console.warn('[Auto Greeter] WhatsApp Web chat list not found. Retrying...');
            setTimeout(startObserver, 2000); // Retry after 2 seconds
        }
    }

    // Start the observer when the page loads
    window.addEventListener('load', startObserver);
    console.log('[Auto Greeter] WhatsApp Web Auto Greeter script loaded.');
})();
```

### 4. 脚本核心解析与自定义
理解脚本的关键部分，将帮助你更好地利用和定制它。

#### 脚本元数据 (`// ==UserScript==`)
这部分提供了脚本的基本信息，如名称、作者、版本等。
*   `@name`: 脚本的显示名称。
*   `@namespace`: 命名空间，通常是你的网站或标识。
*   `@version`: 脚本版本号。
*   `@description`: 脚本的简短描述。
*   `@author`: 你的名字。
*   `@match https://web.whatsapp.com/*`: **关键**！这行告诉Tampermonkey只在访问`https://web.whatsapp.com/*`页面时才运行此脚本。
*   `@grant none`: 表示脚本不需要特殊的权限。

#### 配置常量 (`const GREETING_MESSAGE`, `const MESSAGE_DELAY_MS` 等)
这是你可以定制脚本行为的核心区域：
*   `GREETING_MESSAGE`: 将这里的文本替换成你自己的欢迎语。
*   `MESSAGE_DELAY_MS`: 脚本打开聊天并发送消息之间的延迟时间，用于模拟真实用户操作，避免过快导致的问题。
*   `RECENT_CHAT_THRESHOLD_MS`: 脚本会尝试处理在指定时间范围内有新消息的聊天。
*   `MAX_GREETINGS_PER_CHAT`: 每个聊天最多打招呼的次数。设置为1意味着只打招呼一次。
*   `TARGET_CONTACTS`: （可选）如果你只想对特定的联系人或群组打招呼，可以在这里列出他们的名称或号码。留空则对所有符合条件的聊天生效。
*   `EXCLUDE_CONTACTS`: （可选）如果你不想对某些联系人或群组打招呼，可以在这里列出。

#### 主要逻辑 (`isGreetingRequired`, `processChat`, `MutationObserver`)
*   **`isGreetingRequired(chatElement)`**: 这是判断一个聊天是否需要打招呼的核心函数。它检查：
    *   是否有未读消息指示器 (`[data-icon="unread-count"]`)。
    *   是否在排除列表中。
    *   是否在目标列表中（如果目标列表非空）。
    *   是否已经达到最大打招呼次数。
    *   **重要提示**：WhatsApp网页版的HTML结构可能会随更新而改变。如果脚本失效，很可能是这里的选择器（例如`.x1c4vz4f.x2lahu6`或`[data-tab="10"]`）需要更新。你可以使用浏览器的开发者工具检查最新的DOM结构。
*   **`processChat(chatElement)`**: 这个函数负责打开聊天、输入消息并发送。它模拟了用户的点击、输入和发送操作。
*   **`MutationObserver`**: 这是Web API中的一个强大工具，用于监听DOM树的更改。它会持续监控WhatsApp网页版左侧的聊天列表，一旦有新的聊天项出现或现有聊天项的状态发生变化（例如，出现未读消息），它就会触发回调函数来处理这些变化。

## 高级脚本技巧与考量

一旦你掌握了基本的自动打招呼功能，可以进一步探索更高级的定制选项，以提升脚本的智能性和适应性。

### 1. 条件式问候
你可以根据联系人类型、消息内容或时间等因素发送不同的问候语。例如：
*   **已知联系人 vs. 新联系人**：为新联系人发送更全面的欢迎语，为已知联系人发送更简洁的问候。
*   **群组 vs. 私聊**：为群组发送不同的通知，为私聊发送个性化问候。
*   **关键字触发**：虽然更复杂，但理论上可以扫描入站消息内容中的关键词，然后发送特定的回复（但这更接近聊天机器人，且实现难度更高）。

### 2. 随机化问候语
为了避免重复和更自然，你可以设置一个问候语数组，每次随机选择一条发送。
```javascript
const GREETING_MESSAGES = [
    "您好！感谢您的联系，请问有什么可以帮您？",
    "嗨！很高兴为您服务。请告诉我您的需求。",
    "欢迎！我们已收到您的消息，稍后将有专人为您服务。"
];
// Usage: GREETING_MESSAGES[Math.floor(Math.random() * GREETING_MESSAGES.length)]
```

### 3. 时间段问候
根据一天中的时间发送不同的问候语（例如，“早上好”、“晚上好”）。
```javascript
function getTimeOfDayGreeting() {
    const hour = new Date().getHours();
    if (hour < 12) return "早上好！";
    if (hour < 18) return "下午好！";
    return "晚上好！";
}
// Combine with your main message: `${getTimeOfDayGreeting()} 感谢您的联系...`
```

### 4. 融入动态信息
如果你的脚本能获取到更多上下文信息（例如，从联系人列表或URL中提取信息），你可以将这些信息动态地插入到问候语中，使消息更具个性化。

### 5. 速率限制与反检测机制
为了避免被WhatsApp检测到自动化行为，可以考虑：
*   **随机延迟**: 在消息发送、点击等操作之间增加随机延迟，而不是固定的延迟。
*   **用户代理模拟**: 虽然Tampermonkey默认就是浏览器环境，但一些更复杂的自动化可能会尝试修改用户代理字符串。
*   **避免高频操作**: 避免在短时间内发送大量消息或进行频繁的页面操作。

## 道德考量与最佳实践

在使用任何自动化工具时，尤其是在涉及客户沟通的场景中，遵守道德规范和平台规则至关重要。

### 1. 对用户透明
考虑在你的自动问候语中明确指出这是一条自动化消息，例如“您好！这是一条自动回复。我们已收到您的消息，将尽快有专人与您联系。” 这样可以避免误解，并为客户设定合理的预期。

### 2. 遵守WhatsApp服务条款
WhatsApp的服务条款通常禁止未经授权的自动化或批量消息发送。虽然本脚本是基于浏览器层的模拟，相对风险较小，但滥用仍然可能导致账户被限制或封禁。
*   **避免垃圾邮件行为**：切勿使用自动脚本发送未经请求的商业广告或垃圾信息。
*   **尊重用户隐私**：不要收集或滥用用户数据。

### 3. 脚本的维护与更新
WhatsApp网页版会不定期更新UI和底层代码，这可能导致你的脚本失效。建议：
*   **定期检查**：定期测试脚本功能，确保其正常工作。
*   **学习开发者工具**：掌握使用浏览器开发者工具来检查DOM结构变化，以便在脚本失效时进行修复。
